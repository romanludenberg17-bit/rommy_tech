# rommy tech — сайт канала @rommy_apps

Одностраничник (а теперь четыре страницы) в стиле 2003 года: новости канала, каталог игр со ссылками,
гайды по проблемам, форум и лента новостей индустрии с Playground.ru.

## Файлы

| файл | что это |
|---|---|
| `index.html` | главная: новости канала, 33 игры со ссылками, галерея картинок из постов, Fallout Droid 2.0, эмуляторы |
| `fixes.html` | «Проблемы и исправления»: общая база + 31 гайд по играм (NVSE и 4GB патч для New Vegas — отдельно) |
| `forum.html` | форум: темы по играм, ответы, поиск |
| `news.html` | лента игровой индустрии с Playground.ru |
| `site.css` | все стили (дневная и ночная тема) |
| `common.js` | тема, вкладки, вход/регистрация, Google |
| `config.js` | **твои ключи**: Google Client ID, адрес бэкенда, имя счётчика посетителей |
| `news.json` | снимок ленты для страницы новостей |
| `news-fallback.js` | тот же снимок, если `news.json` не прочитался (локальное открытие) |
| `tools/fetch_news.py` | скрипт, который тянет RSS Playground.ru и пересобирает `news.json` |
| `.github/workflows/news.yml` | робот GitHub: раз в час запускает скрипт и коммитит свежую ленту |
| `img/` | 26 картинок из постов канала |

## Что работает сразу, без сервера

- Все страницы, темы, навигация, поиск и фильтр.
- Каталог из 30 игр с кнопкой «проблемы» у каждой строки.
- 38 раскрывающихся блоков: общая база, два подробных гайда по Fallout и 31 гайд по играм.
- Лента новостей — из `news.json`, а если файл недоступен — из встроенного снимка.

## Общий счётчик посетителей

Внизу каждой страницы и в левой колонке главной — счётчик **за всё время, общий для всех**:

- **посетители** — уникальные: каждый браузер засчитывается один раз (метка в `localStorage`);
- **просмотры** — каждое открытие любой страницы сайта.

Числа хранит бесплатный сервис [Abacus](https://abacus.jasoncameron.dev) — без регистрации и ключей.
Имя счётчика задаётся в `config.js` → `counterNamespace`; если его поменять, счёт начнётся с нуля.
Посмотреть число вручную: `https://abacus.jasoncameron.dev/get/rommy-tech-site/visitors`.
Если сервис недоступен, вместо числа показывается «—», сайт работает как обычно.

## Вход и регистрация: важное ограничение

Сайт статический, поэтому **аккаунты и темы форума хранятся в памяти браузера** (`localStorage`):

- регистрация по почте и паролю работает по-настоящему — пароль хранится только как SHA-256 хеш;
- аккаунт с телефона не появится на компьютере, темы форума не видны другим людям;
- это не безопасность корпоративного уровня: любой, у кого есть доступ к браузеру, может открыть devtools и посмотреть данные.

### Включить настоящий вход через Google

1. Google Cloud Console → создать проект → **APIs & Services → Credentials → Create credentials → OAuth client ID**.
2. Тип — **Web application**. В «Authorized JavaScript origins» добавить адрес сайта (`https://ник.github.io`).
3. Скопировать Client ID и вписать в `config.js`:

```js
window.ROMMY_CONFIG = { googleClientId: '1234567890-abc.apps.googleusercontent.com' };
```

Кнопка «продолжить с Google» начнёт отдавать настоящий аккаунт Google (имя и почту).
Важно: токен проверяется только в браузере — для полноценной проверки на сервере нужен бэкенд.

### Сделать аккаунты и форум общими

Нужен бэкенд: Supabase (бесплатный тариф) или Firebase. Место под ключи уже есть — `backendUrl` и `backendKey`
в `config.js`. С этими ключами `common.js` и `forum.html` переключаются на общий сервер: скажи, и я допишу
запросы к таблицам `profiles` и `posts` (в Supabase это 10 минут работы плюс правила доступа).

## Лента Playground.ru обновляется сама

`tools/fetch_news.py` забирает RSS `https://www.playground.ru/rss/news.xml` и записывает `news.json` +
`news-fallback.js`. Робот GitHub запускает его на cron раз в час:

1. Залей сайт в репозиторий вместе с папками `tools/` и `.github/`.
2. Settings → Actions → General → Workflow permissions → **Read and write permissions**.
3. Вкладка Actions → workflow «news» → Run workflow (первый запуск вручную).
4. Дальше файл обновляется сам; на странице есть кнопка «обновить» для мгновенной перезагрузки ленты.

Если папку `.github` не получается загрузить через веб-интерфейс: создай файл
`.github/workflows/news.yml` вручную (Add file → Create new file, в имени писать путь слэшами)
и вставь содержимое из архива.

## Как выложить на GitHub Pages

1. New repository → имя `rommy-site` → **Public**.
2. Add file → Upload files → перетащить все файлы и папки `img`, `tools`, `.github`.
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту сайт откроется по адресу `https://<ник>.github.io/rommy-site/`.

Альтернатива без GitHub: перетащить папку на `app.netlify.com/drop`.

## Про содержимое

Сайт неофициальный: все ссылки ведут на оригинальные посты канала, игры покупайте, если они есть в продаже.
Гайды собраны из типичных проблем Android-портов; если симптом другой — правится в `fixes.html`,
массив `GUIDES` в конце файла.
